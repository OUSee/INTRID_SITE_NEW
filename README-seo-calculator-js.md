# SEO-калькулятор — демонстрационная frontend-логика

Основа: `intrid-seo-calculator-layout-v3.zip`, подготовленный из последнего пользовательского архива `intrid(20260909-064107).zip`. Дата: 09.09.2026.

## Что изменено

- `js/app.js` — добавлен изолированный модуль SEO-калькулятора; существующие обработчики других форм не изменены.
- `seo.html`, `promotion.html` — включен `data-seo-calculator-mode="mock"`, добавлена ненавязчивая отметка демонстрационного режима и удален неактуальный тестовый ключ из заготовки CAPTCHA. Утвержденные композиция, порядок блоков, кнопки, поля, классы и SCSS сохранены.
- Реальные PHP-контроллеры и существующие API не изменялись. Новые маршруты пока отсутствуют на backend.

## Проверка для ПМ

Откройте `seo.html` или `promotion.html`. Введите `example.ru` (или другой корректный домен) и нажмите кнопку анализа. Через 750 мс появятся предварительно заполненные параметры. URL в демо не запрашивается: для любого корректного адреса используется одинаковый явно обозначенный тестовый набор. На следующем шаге можно изменить селекты, ползунки и точные числовые значения, затем нажать «Рассчитать». Результат и форма заявки появятся без перезагрузки.

Тестовый набор обычного сайта: корпоративный сайт, один регион, средняя конкуренция, 20 разделов, 150 страниц, 21–50 ключевых фраз, возраст домена 24 месяца, история SEO неизвестна. Базовая стоимость — 20 000 ₽, диапазон — 17 000–23 000 ₽/мес., первые результаты — 2–3 месяца, 50%+ запросов в ТОП-10 — 5–8 месяцев.

При выборе «Сайта нет / в разработке» URL не требуется, аудит блокируется, а демо использует Landing Page, 5 разделов, 1 страницу и возраст 0 месяцев. Остальные параметры можно изменить. Чекбоксы дополнительных услуг изначально сняты. Репутация прибавляет 2 000 ₽, GEO — 6 000 ₽ к обеим границам диапазона. Изменение этих чекбоксов после расчета обновляет результат сразу; изменение основных параметров возвращает к подтверждению расчета. Кнопка сброса начинает новый сценарий.

Для заявки достаточно корректного телефона; имя и email необязательны. В демо выводится сообщение, что заявка принята условно и никуда не отправлялась. Повторная отправка блокируется до изменения расчета или сброса. Реальные API и CAPTCHA в mock-режиме не вызываются.

## Расчеты

Правила перенесены из `682e53.xlsx`, листы «Стоимость» и «Сроки». База — 12 000 ₽; к ней прибавляются надбавки по географии, типу сайта, разделам, страницам, фразам и конкуренции. Диапазон — 85% и 115% с округлением до сотен по правилам Excel. Дополнительные услуги прибавляются после округления, без повторного применения процентов. Коэффициенты скидки не вычисляются: используются фиксированные 2 000 и 6 000 ₽.

Уточнение ПМ: разделы 1–5, 6–9, 10–20, 21–50, 51+; последняя категория использует надбавку 6 000 ₽ из Excel. Для сроков сохраняются отдельные интервалы до 100, 101–1000 и более 1000 разделов. Возраст: менее 6 месяцев; от 6 до менее 12; от 12 до 36 включительно; более 36. Если дата регистрации неизвестна, используется категория 1–3 года, но в интерфейсе возраст не выдумывается. История SEO не влияет на цену и сроки. Все расчеты выполняются локально и не требуют ИИ.

## Подключение backend позднее

После реализации и тестирования соответствующих Yii2-ручек измените атрибут корневого компонента на `data-seo-calculator-mode="live"` в обоих представлениях (либо в общем Yii2 partial). Не включайте live-режим до появления серверных обработчиков. Сейчас в `app.js` предусмотрены два вызова `fetch`:

`POST /submit/seo-calculator-analyze` принимает JSON `{ "site": "https://example.ru", "site_missing": false }`. При успешном анализе ожидается:

```json
{
  "success": true,
  "data": {
    "site": "https://example.ru",
    "site_type": "corporate",
    "seo_history": "unknown",
    "region": "one",
    "competition": "medium",
    "keywords": "21-50",
    "sections": 20,
    "pages": 150,
    "age_months": 24
  }
}
```

Если дата регистрации неизвестна, передавайте `age_months: null`; интерфейс применит согласованный fallback. Для нового сайта передавайте `site: ""`, `site_missing: true`, `age_months: 0`. Количество разделов и страниц должно быть положительным целым числом. Схемы значений: `site_type` — `landing`, `corporate`, `catalog`, `store`, `portal`; `seo_history` — `none`, `stopped`, `active`, `unknown`; `region` — `one`, `2-3`, `4-6`, `russia`; `competition` — `low`, `medium`, `high`; `keywords` — `up-to-20`, `21-50`, `51-100`, `101-300`, `301-600`, `over-600`.

`POST /submit/seo-calculator-request` принимает JSON с `name`, `email`, `tel`, `service`, `site`, `form_page`, `g-recaptcha-response` и объектом `calculation: { parameters, result }`. Успешный ответ: `{ "success": true, "data": { "message": "Заявка успешно отправлена." } }`. Ошибки: HTTP 4xx/5xx либо `{ "success": false, "error": "..." }`. Некорректные ответы и ошибки сети отображаются без сброса заполненных полей.

В live-режиме используется `Content-Type: application/json`, `X-Requested-With: XMLHttpRequest`, CSRF-токен из Yii2 meta-тегов и заголовок `X-CSRF-Token`. Сервер должен настроить JSON parser или самостоятельно разобрать raw body. Не отключайте CSRF ради этого калькулятора. Для CAPTCHA необходим действующий ключ Яндекс SmartCaptcha через `window.SMARTCAPTCHA_SITEKEY` или `data-sitekey` внутри компонента; в демо ключ не нужен. Не используйте старый Google reCAPTCHA ключ как ключ SmartCaptcha.

Backend должен повторно валидировать входные параметры и рассчитывать стоимость по утвержденным тарифам, не доверять отправленной браузером сумме. Анализ произвольных URL требует защиты от SSRF, безопасной проверки DNS/редиректов, ограничений на Sitemap, таймаутов, кэширования и лимитов запросов. WHOIS/RDAP определяет возраст домена, а не гарантированную дату создания текущего сайта. ИИ и внешние SEO API в данной версии не подключены.
